# 转专业 / 转行评测集

> 版本：2026-09-07

## 范围

- 转专业 20 题：校内转专业、跨专业读研、辅修、第二学士学位。
- 转行 20 题：软件、工业、设计、会计、销售、教育、运营及目标不明确场景。
- 两个方向均覆盖：信息充足、信息不足、条件冲突、单侧经验、推广内容、结果不明。

## 自动验收

`server/evaluation.test.mjs` 对 40 题逐题检查：

1. 范围和学业路径分类符合预期。
2. 首轮表单保持 4–6 个字段，且字段全部来自本地受控词典。
3. 每题只生成两层、长度受限的搜索计划。
4. 两个方向各 20 题且风险场景覆盖完整。

评测不调用知乎或 DeepSeek，因此可在每次修改后稳定回归。涉及来源质量、模型抽取和真实接口的验收仍由真实样本验证承担。
